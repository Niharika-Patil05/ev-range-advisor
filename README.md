# EV Range Prediction with Calibrated Uncertainty

Physics-informed machine learning for electric-vehicle energy consumption, evaluated
on real logged vehicle data with distribution-shift testing, conformal prediction
intervals, and a battery-health coupling study.

```
route segments → physics road-load baseline → ML residual (log-ratio) → consumption Wh/km
→ range = usable energy (nominal × SoH × temp derate × SoC) / consumption
→ conformal prediction band → advisory layer → Streamlit app
```

Every headline number below is measured on **real logged vehicle data**. Results that
involve simulation are tagged and named as such.

---

## Results

**Consumption prediction** — 480 analysis segments from three 2013 Nissan Leafs in the
[Vehicle Energy Dataset](https://github.com/gsoh/VED), evaluated on **unseen routes**,
5 folds × 5 seeds:

| model | MAPE | |
|---|---|---|
| **hybrid (physics + ML)** | **13.49 ± 0.79 %** | the proposal |
| gradient boosting | 18.06 ± 1.42 % | best pure ML |
| ridge | 19.62 ± 1.49 % | |
| random forest | 20.16 ± 1.69 % | statistically tied with ridge (p = 0.52) |
| physics only | 23.19 ± 0.98 % | no training data at all |
| manufacturer rated range | 59.80 ± 7.58 % | **the problem being solved** |

The hybrid's advantage over the best pure-ML model is significant (paired Wilcoxon
over 104 shared routes, **p = 0.0015**) but modest in the median (2.12 pp), and it
wins on 62 % of routes rather than all.

**Prediction-interval calibration** (target 90 %):

| method | marginal | worst subgroup | width |
|---|---|---|---|
| naive quantile | 0.687 | 0.580 | 0.380 |
| split conformal | 0.948 | 0.898 | 0.684 |
| **Mondrian conformal** | 0.953 | **0.931** | 0.745 |

**Battery State of Health** — 2,359 cycles from 26 NASA cells, leave-one-battery-out:
**4.68 pp MAE**.

**SoH → range coupling** (`COUPLED-SIM`): **≈ 1.63 km of range error per percentage
point of SoH error** at full charge. Consumption-model error contributes **71.9 %** of
range variance; SoH estimation **26.2 %**.

Per-seed metrics, provenance blocks and reproducibility manifests are in
[`reports/`](reports/). Start with
[`reports/HYPOTHESIS_SCORECARD.md`](reports/HYPOTHESIS_SCORECARD.md).

## What makes the evaluation trustworthy

**Every result carries a provenance tag**, enforced in code
(`src/evaluation/provenance.py` refuses to emit a table mixing them):

| tag | meaning |
|---|---|
| `REAL` | every input traces to a physical measurement or a third-party dataset |
| `SYNTHETIC` | generated by this repository's own code — proves the pipeline runs, nothing more |
| `COUPLED-SIM` | real measurements propagated through a **simulated coupling** between datasets that cannot legitimately be joined row-wise |

**Hypotheses were pre-registered.** [`docs/HYPOTHESES.md`](docs/HYPOTHESES.md) was
committed before any data was downloaded. All 15 predictions are scored: **7 supported,
6 refuted, 1 partial, 1 untested.** The refutations are reported in as much detail as
the confirmations.

**An earlier version of this project produced 2.93 % MAPE, and it was meaningless.**
The synthetic generator built consumption from the same physics function the model
consumed as a feature, so the result was the noise floor of an identity written by
hand. Those results are kept in
[`reports/archive_synthetic/`](reports/archive_synthetic/) as a worked example rather
than deleted.

## Findings

**Does the physics prior buy robustness, or only accuracy?**
In-distribution the hybrid wins clearly. Under vehicle shift *with little training
data* the unlearned physics model wins; with adequate data (1,764 PHEV electric-mode
segments across 12 vehicles) the hybrid wins again at 15.99 % against 26.73 %. **The
learned residual's value is conditional on training-data volume, not on vehicle
identity.**

**Three separate predictions of cold-weather failure were all refuted.** Interval
coverage in the coldest subgroup is 0.978 — the *highest* of three groups — and
coverage survives a deliberate violation of exchangeability at 0.929 ± 0.061. One
mechanism explains all three: **auxiliary power is a measured input**, so the model is
told the dominant reason cold trips cost more instead of extrapolating to it. The
contrasting case supports it — cross-fleet transfer degrades where the heater channel
is only 12 % instrumented.

**Improving the consumption model matters ~3× more than improving SoH estimation**
for range accuracy — the opposite of where a battery-focused effort would naturally go.

**Rolling resistance is not identifiable** from this data. Drivetrain efficiency is;
`crr` is not, and a 187 %-wide bootstrap interval says so. Fitting both produces
unstable numbers, so `crr` stays at its datasheet value.

**A degradation projection was deleted rather than shipped.** Calibrating fade against
real cells gave 0.00222 per cycle against a placeholder of 0.00025 — nine times too
small. Wiring the real rate into the old calendar projection predicted a dead pack in
two years. Lab cells reach 80 % SoH in ~90 full-depth cycles; a vehicle pack takes on
the order of a thousand, and nothing here measures that ratio, so the projection now
reports lab cycles and refuses to convert to calendar time.

## Quick start

```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt

pytest -q                                                  # 136 tests, no data needed

python scripts/fetch_data.py --list                        # sources and licences
python scripts/fetch_data.py --dataset ved   --extract     # ~176 MB → 3.0 GB
python scripts/fetch_data.py --dataset eved  --extract     # ~656 MB → 6.1 GB
python scripts/fetch_data.py --dataset nasa_pcoe --extract # battery cells

python -m src.experiments.e1_model_comparison              # headline table
python -m src.experiments.e2_shift_ladder                  # distribution shift
python -m src.experiments.e_rq2_uncertainty                # interval calibration
python -m src.experiments.e6_soh_range_coupling            # SoH → range

python scripts/train_real_system.py                        # model the app serves
streamlit run app/streamlit_app.py
```

The test suite builds synthetic frames in each dataset's schema, so it runs on a
machine that has never downloaded the ~9 GB of data.

## Data

| dataset | role | licence |
|---|---|---|
| [VED](https://github.com/gsoh/VED) | 3 BEVs + 24 PHEVs, Ann Arbor 2017–18, pack current/voltage | Apache-2.0 |
| [eVED](https://github.com/zhangsl2013/eVED) | map-matched GPS, elevation, speed limits. **Superset of VED** | Apache-2.0 |
| [NASA PCoE](https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/) | 26 Li-ion cells to end of life | US Gov public domain |
| [Open-Meteo archive](https://open-meteo.com/en/docs/historical-weather-api) | historical weather (join validated; wind/rain not yet used as features) | CC-BY 4.0 |

Provenance, sampling rates, verified join keys and known limitations:
[`data/manifest.yaml`](data/manifest.yaml).

Two data findings worth noting, both contradicting the dataset documentation:
**negative pack current means discharge** (the signed integral is negative in 100.0 %
of trips with a SoC drop), and **sampling is irregular** (0.1–13.4 s, median 0.9 s)
rather than the published fixed rates, so energy must be integrated with actual time
deltas.

## Limitations

1. **Two usable vehicles.** VED has 3 BEVs; one contributes 10 segments. Vehicle-level
   claims rest on n = 2, mitigated but not solved by the 23-vehicle PHEV fleet.
2. **Segments, not trips.** De-identification removed rows near each journey's ends, so
   a record is a **fragment**, median 3.6 km.
3. **Flat terrain.** 96.7 % of rows have |gradient| < 0.5 %. Steep-terrain performance
   is demonstrated, never validated.
4. **Payload unobserved**, so vehicle mass is an assumption (±5 %).
5. **`crr` is not identifiable** from this data; it stays at its datasheet value.
6. **Lab cells are not vehicle packs.** NASA cells are 2 Ah 18650s.
7. **No public dataset has trips and pack SoH for the same vehicle** — hence `COUPLED-SIM`.
8. **Observational data: associations only.** No causal claim is made anywhere.
9. **One city, one year.** Ann Arbor, Michigan, 2017–18.
10. **Wind and rain are not yet features**, though the weather join is validated.

## Layout

```
src/data/          ved.py (+PHEV electric mode), nasa.py, loaders

src/models/        range models, conformal/CQR/Mondrian intervals, SoH, coupling
src/calibration/   road-load parameter identification

src/advisor/       range band, counterfactual explanations, rules
app/               Streamlit app
docs/              methodology, data verification, findings, hypotheses, references
```

## Methodology

- **Grouped splits everywhere**, asserted at runtime. Each protocol declares what it
  guarantees to hold disjoint (`disjoint_keys`); experiments assert exactly that and
  no more.
- **Attrition logged.** Every excluded record is counted with a reason.
- **5 seeds**, mean ± std. No single-seed result is reported.
- **Every experiment writes** `MANIFEST.json` (git revision, seeds, data hashes) and
  `EVIDENCE.md` (measured / derived / external / simulated / assumed).
- A **leakage demonstration** quantifies what a naive random split would have
  fabricated: 8–16 % of every learned model's error.
