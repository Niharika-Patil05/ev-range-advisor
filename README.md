# Route-Aware, Uncertainty-Aware EV Range Prediction with an SoH-Coupled Battery Advisor

Final-year project, Dept. of Electrical Engineering, ADCET Ashta.
Evolution of the minor-project synopsis *"AI-Based EV Range Prediction and Battery Health Advisor"*.

```
route segments -> physics road-load baseline -> ML residual (log-ratio) -> consumption Wh/km
-> range = usable energy (nominal x SoH x temp derate x SoC) / consumption -> conformal band
-> advisor (counterfactual explanations + rules) -> Streamlit app
```

**The architecture is unchanged from the original scaffold. What changed is the evidence.**
Every headline number below is measured on **real logged vehicle data**, not simulated.

---

## Results on real data

**Consumption prediction**, 480 analysis segments from three 2013 Nissan Leafs in the
[Vehicle Energy Dataset](https://github.com/gsoh/VED), evaluated on **unseen routes**,
5 folds × 5 seeds:

| model | MAPE | |
|---|---|---|
| **hybrid (physics + ML)** | **13.49 ± 0.79 %** | the proposal |
| gradient boosting | 18.06 ± 1.42 % | best pure ML |
| ridge | 19.62 ± 1.49 % | |
| random forest | 20.16 ± 1.69 % | statistically tied with ridge (p = 0.52) |
| physics only | 23.19 ± 0.98 % | no training data at all |
| manufacturer rated range | 59.80 ± 7.58 % | **the problem this project exists to solve** |

The hybrid's advantage over the best pure-ML model is significant (paired Wilcoxon
over 104 shared routes, **p = 0.0015**) but modest in the median (2.12 pp), and it
wins on 62 % of routes rather than all.

**Range-band calibration** (target 90 %):

| method | marginal | worst subgroup | width |
|---|---|---|---|
| naive quantile *(the original)* | 0.687 | 0.580 | 0.380 |
| split conformal | 0.948 | 0.898 | 0.684 |
| **Mondrian conformal** | 0.953 | **0.931** | 0.745 |

**Battery State of Health**, 2,359 cycles from 26 real NASA cells, leave-one-battery-out:
**4.68 pp MAE** — 4.2× worse than this project's own earlier synthetic figure, and that
is the honest number.

**SoH → range coupling** (`COUPLED-SIM`, see below): **≈ 1.63 km of range error per
percentage point of SoH error** at full charge. Consumption-model error contributes
**71.9 %** of range variance; SoH estimation **26.2 %**.

Full reports with per-seed metrics, provenance blocks and reproducibility manifests
are in [`reports/`](reports/). Start with
[`reports/HYPOTHESIS_SCORECARD.md`](reports/HYPOTHESIS_SCORECARD.md).

## How to read the evidence

Every result carries a **provenance tag**, enforced in code (`src/evaluation/provenance.py`):

| tag | meaning |
|---|---|
| `REAL` | every input traces to a physical measurement or a third-party dataset |
| `SYNTHETIC` | generated by our own code. Proves the pipeline runs, says nothing about accuracy |
| `COUPLED-SIM` | real measurements propagated through a **simulated coupling** between datasets that cannot legitimately be joined row-wise |

`COUPLED-SIM` applies to the SoH→range study (RQ3) and is not optional wording: no
public dataset contains both a vehicle's trips and its own pack's SoH trajectory, so
that result is a **propagation study, not end-to-end validation**.

**The old synthetic results are archived, not deleted**, in
[`reports/archive_synthetic/`](reports/archive_synthetic/) with an explanation of why
they were circular — the generator built consumption from the same physics function
the model used as a feature, so the 2.93 % MAPE was the noise floor of an identity we
had written ourselves. They are kept as a worked example of the error.

## Research questions and what was found

**RQ1 — does the physics prior buy robustness, or only accuracy?**
In-distribution the hybrid wins clearly. Under vehicle shift *with little training
data* the unlearned physics model wins; with adequate data (1,764 PHEV-electric
segments, 12 vehicles) the hybrid wins again at 15.99 % against 26.73 %. **The learned
residual's value is conditional on training-data volume, not on vehicle identity.**

**RQ2 — is the range band trustworthy where it matters?**
The original quantile band claims 90 % and delivers **69 %**. Conformalising fixes it.
Mondrian raises worst-subgroup coverage to 0.931 for ~9 % more width. Three
pre-registered predictions of cold-weather failure were all **refuted**, for one
reason: auxiliary power is a *measured* input, so the model is told the dominant
reason cold trips cost more.

**RQ3 — how much of the range error is the battery's fault?**
Less than expected. Consumption error dominates at 71.9 % against 26.2 % for SoH.
**Improving the consumption model matters about three times more than improving SoH
estimation.**

## Quick start

```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt

python scripts/fetch_data.py --list                        # what data, what licence
python scripts/fetch_data.py --dataset ved   --extract     # ~176 MB -> 3.0 GB
python scripts/fetch_data.py --dataset eved  --extract     # ~656 MB -> 6.1 GB
python scripts/fetch_data.py --dataset nasa_pcoe --extract # battery cells

python -m src.experiments.e1_model_comparison              # the headline table
python -m src.experiments.e2_shift_ladder                  # RQ1
python -m src.experiments.e_rq2_uncertainty                # RQ2
python -m src.experiments.e6_soh_range_coupling            # RQ3

pytest -q                                                  # 109 tests, no data needed
streamlit run app/streamlit_app.py
```

The test suite builds synthetic frames in each dataset's schema, so it runs on a
machine that has never downloaded the ~9 GB of data.

## Honest limitations — put these in the report

1. **Two usable vehicles.** VED has 3 BEVs; one contributes 10 segments. Vehicle-level
   claims rest on n = 2, mitigated but not solved by the 23-vehicle PHEV fleet.
2. **Segments, not trips.** De-identification removed rows near each journey's ends, so
   a record is a **fragment**, median 3.6 km.
3. **Flat terrain.** 96.7 % of rows have |gradient| < 0.5 %. Steep-terrain performance
   is *demonstrated*, never *validated*.
4. **Payload unobserved**, so vehicle mass is an assumption (±5 %).
5. **`crr` is not identifiable** from this data (E7); it stays at its datasheet value.
6. **Lab cells are not vehicle packs.** NASA cells are 2 Ah 18650s.
7. **No trips + pack SoH for the same vehicle exist publicly** — hence `COUPLED-SIM`.
8. **Observational data: associations only.** No causal claim is made anywhere.
9. **Michigan, one year.** No Indian road, traffic or climate data underpins these results.
10. **Wind and rain are not yet features**, though the weather join is validated.

## Methodology commitments

- **Pre-registration.** `docs/HYPOTHESES.md` was committed before any data was
  downloaded. All 15 hypotheses are scored, including the 6 that were refuted.
- **Grouped splits everywhere**, asserted at runtime. Each protocol declares what it
  guarantees to hold disjoint (`disjoint_keys`), and experiments assert exactly that.
- **Attrition logged.** Every excluded record is counted with a reason.
- **5 seeds**, mean ± std. No single-seed result is reported.
- **Every experiment writes** `MANIFEST.json` (git revision, seeds, data hashes) and
  `EVIDENCE.md` (measured / derived / external / simulated / assumed).
