# Archived synthetic results — NOT EVIDENCE

These are the results the project produced before real data was introduced. They are
kept, unchanged, for the record. **No number in this folder may be quoted in the
report, the paper, the viva, or the app.**

## Why they are not evidence

The synthetic "ground truth" was generated by `_true_wh_per_km()` in
`src/data/synthetic.py`, which calls the **same** `segment_energy_wh()` function that
produces the `phys_wh_km` feature the hybrid model consumes. So, by construction:

```
log(y_true / phys_wh_km) = a smooth function of {rain, temp_c, soh, style} + 3 % noise
```

and those four variables are handed to the model as input features. The hybrid's
**2.93 % MAPE is the 3 % noise floor** — it recovered an algebraic identity we wrote
ourselves. It discovered nothing.

The same circularity invalidates the rest:

| File | Why it is not evidence |
|---|---|
| `range_results.csv` | Hybrid 2.93 % MAPE is circular, as above |
| `ablation.csv` | "Weather matters" is guaranteed — `crr_scale` is *built from* `rain` and `temp_c` |
| `soh_results.csv` | LOBO MAE 1.11 pp is trivial — every health indicator is a monotone function of `soh` plus small noise. Real cells give 2–5 pp |
| `uncertainty.csv` | Coverage is measured against a synthetic residual distribution. The quantile under-coverage (0.73 vs 0.90) is, however, a **real** defect worth fixing |
| `summary.json`, `fig_*.png` | Derived from the above |

## What they are good for

Exactly two things:

1. **Proving the pipeline executes end to end** — which they did, successfully.
2. **A worked example of circular evaluation.** Keeping them, labelled, documents how
   the error was found and corrected. That is a strength to present, not an
   embarrassment to hide.

Real results live in `reports/<experiment_id>/`, each with a `MANIFEST.json`
(seeds, code revision, data hashes) and an `EVIDENCE.md` stating what was measured,
derived, external, simulated and assumed.

See `docs/00_INVESTIGATION_REPORT.md` §3 for the full analysis.
